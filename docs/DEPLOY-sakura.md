# さくらのレンタルサーバへの公開手順

ローカルで作ったサイトを、さくらのレンタルサーバに載せる手順です。コマンド操作は不要で、ブラウザだけで進められます。
コントロールパネルのメニュー名は、プランや時期によって少し違うことがあります。

---

## 0. 準備するもの

- さくらのレンタルサーバの契約（**スタンダード以上**を推奨。PHP 8.2 以上と MySQL 8 が使えること）
- 公開するドメイン（例：netelly.co.jp）。さくらで管理していない場合は、ドメイン会社側でネームサーバーなどを設定します
- `netelly-theme.zip`（テーマ一式。`npm run zip` で作れます）
- 問い合わせの通知を受け取るメールアドレス（例：info@netelly.co.jp）

> **すでにさくらで別のサイトを公開している場合**：いきなり本番ドメインに入れず、まずサブドメイン（例：new.netelly.co.jp）で作って確認し、最後に切り替えると安全です。

---

## 1. サーバー側の設定（コントロールパネル）

1. **ドメインを追加**し、公開フォルダ（例：`/home/アカウント名/www/netelly`）を決める
2. そのドメインの **無料SSL（Let's Encrypt）** を有効にする（https で開けるように）
3. **PHP のバージョン**を 8.2 以上にする
4. **WordPress のクイックインストール**を実行する
   - インストール先：手順1のドメイン／フォルダ
   - データベース：新規作成（文字コードは utf8mb4）
   - サイト名：Netelly、ユーザー名とパスワードは推測されにくいものに（`admin` は避ける）
   - 管理者メール：通知を受け取りたいアドレス

---

## 2. WordPress の管理画面での作業

`https://（ドメイン）/wp-admin/` にログインして、上から順に進めます。

### 2-1. プラグインを3つ入れる
プラグイン › 新規追加 で次の3つを検索し、「今すぐインストール」→「有効化」します。

| プラグイン | 役割 |
|---|---|
| Secure Custom Fields | 各ページの入力欄 |
| Polylang | 日本語／英語の切り替え |
| Snow Monkey Forms | お問い合わせフォーム |

Polylang を有効化すると初期設定の画面（ウィザード）が開きますが、**閉じて（スキップして）かまいません**。言語の設定は手順2-3で自動的に行います。

### 2-2. テーマを入れる
外観 › テーマ › 新規追加 › **テーマのアップロード** で `netelly-theme.zip` を選び、「今すぐインストール」→「有効化」します。

> 「アップロードしたファイルは php.ini で定義された upload_max_filesize を超えています」と出る場合は、コントロールパネルの PHP 設定（php.ini）で `upload_max_filesize = 32M` と `post_max_size = 32M` にしてから再度アップロードしてください。
> FTP が使える場合は、zip を展開した `netelly-theme` フォルダを `wp-content/themes/` にアップロードしても同じです。

### 2-3. 初期データを入れる（最初の1回だけ）
ツール › **Netelly 初期データ** を開き、「上書きされることを理解しました」にチェックを入れて「初期データを作成する」を押します（10秒ほど）。

これで、全ページ（日本語・英語）・作品・ニュース・募集職種・お問い合わせフォーム・メニュー・サイト設定・プレスキットのロゴ素材が入ります。

> **公開後に二度と押さないでください**。管理画面で編集した文章が初期値に戻ります。

### 2-4. 公開前に必ず変える設定

| 場所 | 内容 |
|---|---|
| Snow Monkey Forms › 「お問い合わせ」「お問い合わせ (EN)」 › 管理者宛メール | 送信先を問い合わせを受けるアドレスに（初期値は WordPress の管理者メール） |
| 同 › 自動返信メール | 差出人名・本文を確認 |
| 設定 › Snow Monkey Forms（reCAPTCHA） | reCAPTCHA v3 のサイトキー／シークレットキー（迷惑メール対策） |
| サイト設定 › 日本語 / English | 会社情報・連絡先・SNS の URL・Creators Fund の URL |
| サイト設定 › トップ：ヒーロー | **ポスター画像を必ず設定**（表示速度に大きく影響します）。動画もあればここで |
| 設定 › 一般 | キャッチフレーズは空でOK。タイムゾーンが「東京」になっていること |
| 設定 › 表示設定 | 「検索エンジンがサイトをインデックスしないようにする」は、**確認用のあいだはチェック**、本番公開時に**外す** |

### 2-5. 写真・動画・文章を入れる
写真や動画はメディアからアップロードし、各ページの編集画面とサイト設定で差し替えます。どこで何を編集するかは、テーマの `README.md` の「どこで編集するか」の表を見てください。

---

### 2-6. 検索・AI検索のための入力（公開前に）

| 場所 | 入れるもの |
|---|---|
| サイト設定 › 代表メッセージ | 代表写真、**よみがな**、**プロフィール文**（経歴・専門・実績を事実ベースで100〜300字）、**経歴**、**本人の公式プロフィールURL**（X・LinkedIn・note・Wikipedia など） |
| サイト設定 › SEO・SNS共有 | トップのタイトル、SNS共有画像、設立日、**会社の公式プロフィールURL**（PR TIMES の企業ページ、LinkedIn、Wikipedia など） |
| サイト設定 › 外部リンク | 会社の公式SNSのURL（自動で検索エンジン向け情報に含まれます） |

逆に、本人のSNSや PR TIMES・取材記事のプロフィール欄からも **https://netelly.co.jp/message/** へリンクしてもらうと、Google が「同一人物」と結びつけやすくなります。

## 3. 表示速度の設定（任意・おすすめ）

公開フォルダの `.htaccess` の **一番上** に次を追記すると、ファイルの圧縮とブラウザキャッシュが効いて速くなります（WordPress が書いた `# BEGIN WordPress` の部分は消さないでください）。

```apache
# 圧縮
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css application/javascript image/svg+xml application/json
</IfModule>

# ブラウザキャッシュ（テーマの CSS / JS はファイル名が変わるので長期間でOK）
<IfModule mod_expires.c>
  ExpiresActive On
  ExpiresByType text/css "access plus 1 year"
  ExpiresByType application/javascript "access plus 1 year"
  ExpiresByType font/woff2 "access plus 1 year"
  ExpiresByType image/webp "access plus 1 month"
  ExpiresByType image/png "access plus 1 month"
  ExpiresByType image/jpeg "access plus 1 month"
  ExpiresByType image/svg+xml "access plus 1 month"
</IfModule>
```

## 3.5 いまの netelly.co.jp からの切り替え（既存サイトがある場合）

スタンダードプランでは、次の順で進めると今のサイトを止めずに切り替えられます。

1. サブドメイン（例：`new.netelly.co.jp`）を追加し、そこに手順1〜2で新サイトを作る。表示設定で「インデックスしない」にチェック
2. 確認が終わったら、今のサイトのフォルダをバックアップ（ファイル一式とデータベース）
3. コントロールパネルで `netelly.co.jp` の公開フォルダを新サイトのフォルダに切り替える
4. WordPress の 設定 › 一般 の「WordPress アドレス」「サイトアドレス」を `https://netelly.co.jp` にする（**切り替え直後にログインできなくなった場合は、先にここを変えてからフォルダを切り替えます**）
5. 表示設定の「インデックスしない」のチェックを外す
6. **旧サイトのURLからの転送（301）**：管理画面 › サイト設定 › **旧サイトからの転送** に「旧URLのパス → 新URL」を登録します（コード不要）。初期値として、Google の `site:netelly.co.jp` で確認した旧URL（/publish・/terms・/privacy-policy・/posts/…・/funding-commingsoon など）の転送と、テンプレートの見本ページ（/templates・/pricing）の「削除済み（410）」を入れてあります。それ以外にも旧サイトの実際のURLは Google で `site:netelly.co.jp` と検索するか、Search Console の「ページ」で確認して、検索に出ているURLをすべて登録してください。
7. **Google Search Console** に `netelly.co.jp` を登録し、サイトマップ `https://netelly.co.jp/wp-sitemap.xml` を送信。代表メッセージページは「URL検査」→「インデックス登録をリクエスト」

## 4. 公開前チェックリスト

- [ ] https で開ける（鍵マーク）／ http から https に自動で移る
- [ ] 日本語・英語の全ページが開く（例：`/company/` と `/en/company/`）
- [ ] JP / EN の切り替えで同じページの反対の言語に移る
- [ ] お問い合わせを日本語・英語で1回ずつ送信し、**管理者宛と自動返信の両方が届く**
- [ ] 採用ページの職種 → お問い合わせで「採用」が選ばれ、職種名が入る
- [ ] プレスキットのロゴと ZIP がダウンロードできる
- [ ] スマホで表示を確認（メニューの開閉、フォームの入力）
- [ ] 表示設定の「インデックスしない」のチェックを外した
- [ ] サイトのバックアップ設定（さくらのバックアップ機能、または WordPress のバックアッププラグイン）
- [ ] 共有テスト：X や LINE に URL を貼って画像付きで出る
- [ ] Google の「リッチリザルトテスト」で トップ・代表メッセージ・ニュース記事 にエラーがない

---

## 5. テーマを更新するとき

コードを直したら `npm run zip` で新しい `netelly-theme.zip` を作り、外観 › テーマ › 新規追加 › テーマのアップロード で同じ zip を入れて「アップロードしたもので現在のものを置き換える」を選びます。**初期データの作成は押しません。**
