# KENTA OTOZAKI — director site

Static one-page site (no WordPress). Files: `index.html`, `og.png` (share image).

## Publish on Sakura
1. Add the domain in the Sakura control panel (ドメイン/SSL), Web公開フォルダー e.g. `/kentaotozaki`.
2. Upload `index.html` and `og.png` into `~/www/kentaotozaki/` (ファイルマネージャー).
3. Point the domain's DNS (A record) to the server, then turn on free SSL.

## Edit
Open `index.html` and look for `<!-- EDIT -->` comments: name, works (title, year, link, colours), about text, contact address.
